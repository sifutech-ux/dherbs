# L&A World

Buying house for L&A World Sdn Bhd. Domain: [lnaworld.my](https://lnaworld.my).

```bash
npm install
npm run dev
npm run build
```

The production build is the `dist` folder. On Hostinger, upload its contents to the site root. `public/.htaccess` is copied into `dist` so the five pages resolve on Apache.
